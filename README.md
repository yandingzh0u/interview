# 面试题库

本地运行的面试题背题工具。自己录题，按答题骨架分段，空格逐段揭示答案。

## 运行

Windows 双击 **`启动.bat`**，浏览器会自动打开 `http://127.0.0.1:7788`。

或者命令行：

```bash
node server.mjs
```

需要 Node.js 18+。零依赖，不用 `npm install`。关闭那个黑窗口就是停止服务，数据已经存盘。

## 怎么用

1. 题库页 → 「新建题目」，或者「批量导入」粘一段
2. 选**一级 Tag**（决定按什么顺序想）和**二级问法**（决定每一步叫什么）
3. 按骨架分段填答案，每段一个输入框
4. 背诵页按空格逐段揭示

键盘：

| 键 | 作用 |
|---|---|
| `空格` | 展开下一段 |
| `→` | 下一题 |
| `←` | 上一题（直接全展开） |

## 五个一级 Tag

| 一级 Tag | 骨架动作 |
|---|---|
| 解释原理 | 下判断 → 拆要点 → 讲关系 → 收口 |
| 对比选型 | 立维度 → 比差异 → 算代价 → 给条件 |
| 设计实现 | 定边界 → 拆结构 → 讲流程 → 防异常 → 做验证 |
| 排障治理 | 看现象 → 分原因 → 找证据 → 做修复 → 防复发 |
| 评测优化 | 立基线 → 定指标 → 做实验 → 看结果 → 讲取舍 |

**二级问法只换每一步的措辞，不换骨架。** 比如「设计实现 / 怎么落地」显示成：

```
1 定边界（业务环境） → 2 拆结构（接入方案） → 3 讲流程（部署上线） → 4 防异常（监控回滚） → 5 做验证（效果验证）
```

## 数据

| 文件 | 作用 |
|---|---|
| `data/bank.jsonl` | 题库，一行一道题 |
| `data/frameworks.json` | 骨架配置，改这里全库生效 |

备份就是复制 `bank.jsonl`。它也可以直接用记事本改，改完刷新页面就生效——服务端会比对文件修改时间自动重新载入；某一行写坏了只会跳过那一行，不会毁掉整个题库。

## 批量导入格式

```
Q: Agent 的上下文工程怎么设计？
CAT: 设计实现 / 如何设计
SEG: 先明确任务类型、上下文窗口和延迟预算。
SEG: 按系统指令、任务状态、历史消息、工具结果四块装配。
SEG: 每轮按当前任务重新装配模型输入。
SEG: 超长时压缩历史，保留必要状态。
SEG: 用任务完成率和上下文成本验证。
FU: 压缩会不会丢关键信息？ | 看任务成功率，不看压缩率
```

- `Q` 必填，`CAT` 建议填
- `SEG` 一行一段，对应骨架的每一步，可以以后再补
- `FU` 是追问，`|` 后面是答题提示
- 重复的题会自动跳过

## 技术

只用 Node 内置模块，没有第三方依赖。Markdown 渲染和代码高亮用 `vendor/` 里的 marked + highlight.js，已经本地化，断网也能跑。

写入采用 `.tmp` → `rename` 的原子方式，写到一半断电不会产生半截文件。
